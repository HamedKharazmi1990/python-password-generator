# Python Password Generator 🔐

A simple customizable password generator built with Python.

## Features

* Choose the number of letters
* Choose the number of numbers
* Choose the number of symbols
* Generate a random password

## Technologies

* Python
* Random module
* String module

## How to Run

Clone the repository:

```bash
git clone https://github.com/HamedKharazmi1990/python-password-generator.git
```

Navigate to the project:

```bash
cd python-password-generator
```

Run the program:

```bash
python main.py
```

## Example

```text
How many letters do you want? 8
How many numbers do you want? 3
How many symbols do you want? 2

Generated password:
xKpQmTaR7@2#91
```
